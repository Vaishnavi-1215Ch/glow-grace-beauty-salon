# Glow & Grace Beauty Studio

A fictional, responsive beauty-studio website created as a portfolio demonstration using plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Features

- Responsive navigation with an accessible mobile menu
- Homepage, studio story, treatment menu, photo gallery, booking request form, testimonials, and contact details
- Smooth anchor navigation and subtle scroll-reveal effects
- Keyboard support, reduced-motion handling, descriptive image text, and responsive form controls
- External photography from Unsplash and typography from Google Fonts

## Demo notes

All studio details, pricing, and testimonials are fictional. The appointment form validates its fields and displays a confirmation in the browser, but does not send or store a booking. Replace the sample contact details and connect a booking service before using this site for a real business.
